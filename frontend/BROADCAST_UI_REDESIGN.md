# 群发消息UI重新设计说明

## 📋 设计概述

全新的群发消息界面采用双模块设计，操作更加简洁直观。

---

## 🎨 主要改进

### 1. **模块化设计**
- **全部群发**：手动选择多个群组进行群发
- **分组群发**：选择一个分组，一键发送到该分组的所有群组

### 2. **简化操作流程**
- 取消复杂的表格和多层嵌套
- 所有操作在一个页面内完成
- 群组默认为未选中状态

### 3. **清晰的视觉层次**
- 顶部导航Tab切换两个模块
- 每个模块内容独立，互不干扰
- 重要操作按钮醒目突出

---

## 📱 功能详解

### 模块一：全部群发

#### 布局结构
```
┌─────────────────────────────────────────┐
│ 搜索框 | [全选] [取消全选] [刷新]        │
├─────────────────────────────────────────┤
│ 已选择 X 个群组，共 Y 个可用群组         │
├─────────────────────────────────────────┤
│ ┌─ 选择群组 ────────────────────┐      │
│ │ □ 群组A    [成员数: 100]      │      │
│ │ □ 群组B    [成员数: 50]       │      │
│ │ □ 群组C    [成员数: 200]      │      │
│ └────────────────────────────────┘      │
├─────────────────────────────────────────┤
│ 消息内容 (字数统计)                     │
│ ┌─────────────────────────────────┐    │
│ │ [文本输入框 - 6行]              │    │
│ └─────────────────────────────────┘    │
│                                          │
│ 发送延迟: [3000毫秒]  [开始群发] ──→   │
└─────────────────────────────────────────┘
```

#### 主要功能
1. **搜索过滤**：实时搜索群组名称
2. **批量操作**：
   - 全选：选中所有搜索结果
   - 取消全选：清空所有选择
   - 刷新：更新群组列表
3. **群组选择**：
   - 点击整行或复选框进行选择
   - 已选群组背景高亮显示
   - 显示成员数量徽章
4. **消息编辑**：
   - 最多4096字符
   - 实时字数统计
   - 可调整发送延迟（1000-60000ms）
5. **发送控制**：
   - 未选择群组或消息为空时禁用按钮
   - 显示将要发送的群组数量

### 模块二：分组群发

#### 布局结构
```
┌──────────────┬────────────────────────────┐
│ 选择分组     │ 编写消息                    │
│ [刷新]       │                             │
├──────────────┤                             │
│ [图标] 分组A │ 将发送到分组：分组A (5个群组)│
│   5个群组    │                             │
│              │ 消息内容                     │
│ [ ] 分组B    │ ┌────────────────────┐     │
│   3个群组    │ │ [文本输入框-10行]  │     │
│              │ └────────────────────┘     │
│ [ ] 分组C    │                             │
│   8个群组    │ 发送延迟: [3000毫秒]        │
│              │                             │
│              │ ┌──────────────────┐        │
│              │ │  [立即发送]      │        │
│              │ └──────────────────┘        │
└──────────────┴────────────────────────────┘
```

#### 主要功能
1. **分组选择**（左侧）：
   - 显示所有可用分组
   - 带颜色标识的图标
   - 显示每个分组的群组数量
   - 点击选中，边框高亮
2. **消息编辑**（右侧）：
   - 未选择分组时显示空状态提示
   - 选择分组后自动激活编辑区
   - 显示当前选中的分组信息
   - 大号发送按钮
3. **一键发送**：
   - 自动将消息发送到分组内所有群组
   - 发送后清空消息内容
   - 自动取消分组选择

## 🎯 操作流程

### 全部群发流程
1. 打开"全部群发"标签
2. （可选）使用搜索框过滤群组
3. 点击群组或复选框进行选择
4. 或点击"全选"按钮选择所有
5. 在消息框输入内容
6. （可选）调整发送延迟
7. 点击"开始群发"
8. 右下角出现进度浮窗
9. 发送完成后自动清空选择和消息

### 分组群发流程
1. 打开"分组群发"标签
2. 在左侧点击选择一个分组
3. 右侧自动激活编辑区
4. 输入要发送的消息内容
5. （可选）调整发送延迟
6. 点击"立即发送"
7. 右下角出现进度浮窗
8. 发送完成后自动清空

## 🔧 技术实现

### 核心技术栈
- React 18 + Hooks
- Ant Design 5.x
- 受控组件模式

### 状态管理
```javascript
// 通用状态
- loading: 加载状态
- broadcastProgress: 群发进度
- progressPolling: 轮询定时器

// 全部群发状态
- allBroadcastMessage: 消息内容
- allBroadcastDelay: 发送延迟
- selectedGroups: 已选群组ID数组
- searchText: 搜索关键词

// 分组群发状态
- categories: 分组列表
- selectedCategory: 当前选中分组ID
- categoryMessage: 消息内容
- categoryDelay: 发送延迟
```

### 关键优化
1. **过滤缓存**：使用`useMemo`避免重复计算
2. **清理副作用**：组件卸载时清理定时器
3. **防抖优化**：搜索输入自动触发过滤
4. **条件渲染**：按需加载内容减少DOM节点
